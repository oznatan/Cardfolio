# מעקב תיק קלפים

אפליקציית ווב מקומית שעוקבת אחרי תיק **Main** ב-Collectr, שומרת כמה שילמת ובאיזה שער דולר, ומשווה לשווי היום.

## הפעלה

לחיצה כפולה על `start.bat`. השרת עולה ברקע בלי חלון, והאפליקציה נפתחת בכתובת http://localhost:8787. אין מה להתקין.

השרת ממשיך לרוץ עד שעוצרים אותו עם `stop.bat` או עד שהמחשב נכבה. לחיצה נוספת על `start.bat` רק פותחת את האפליקציה שוב. אם יש תקלה, פרטים נשמרים ב-`data/server.log`.

## כמה תיקים

**ניהול תיקים** (ליד שם האפליקציה) מוסיף תיק לפי קישור לפרופיל ב-Collectr, ומאפשר לבחור איזה תיק בפרופיל לעקוב. לכל תיק נשמרים בנפרד המוצרים, הרכישות וההיסטוריה, ובוחרים ביניהם מהרשימה שליד השם. הסרת תיק לא מוחקת את הנתונים שלו מהמחשב. בתיק חדש מחירי המדורגים כבויים, כי המכסה של CompSniper משותפת לכל התיקים. הבדיקה המהירה עובדת רק לתיק הראשי של כל פרופיל; לשאר התיקים מעדכנים בסנכרון מלא.

## עדכון נתונים

- **רענון מהיר:** קורה בכל פתיחה. קורא מהדף הציבורי את השווי הכולל, את ספירת הפריטים ואת 30 המוצרים הראשונים, ומתריע אם התיק השתנה.
- **סנכרון מלא:** הכפתור בראש העמוד מסביר איך להוסיף סימניה. לוחצים עליה בדף הפרופיל ב-Collectr, והיא קוראת את כל התיקים שבו. האפליקציה שומרת רק את התיקים שבמעקב. זה נדרש כי Collectr חוסם בקשות שלא מגיעות מדפדפן.

## מחירי קלפים מדורגים

הערך של קלף מדורג הוא ממוצע 5 המכירות האחרונות שתואמות לקלף ולדירוג: מכירות פומביות מ-eBay, עם השלמה מ-Fanatics כשאין מספיק. הנתונים מגיעים משירות CompSniper, והעדכון רץ פעם בשבוע כשהאפליקציה פתוחה.

**הגדרה:** נרשמים ל-CompSniper במסלול Basic החינמי, **בלי להזין אמצעי תשלום**, ומדביקים את מפתח ה-API במסך **מחירי מדורגים**. המפתח נשמר רק ב-`data/compsniper-key.txt`. האפליקציה עוצרת ב-95 בקשות בחודש. קלף עם פחות מ-5 מכירות מתאימות נשאר לפי Collectr ונבדק שוב בעדכון הבא.

**גיבוי בלי מפתח:** לכל קלף מדורג מופיע בטבלה כפתור **eBay** שפותח את החיפוש, ובו לוחצים על הסימניה "קריאת מכירות eBay" ומאשרים את המכירות.

## מקורות

- מחירים: Collectr בדולרים, וקלפים מדורגים שעודכנו לפי מכירות פומביות ב-eBay.
- שערים: שער יציג של בנק ישראל. ביום בלי פרסום נלקח השער האחרון שפורסם לפניו.

## הנתונים שלך

הכול נשמר רק במחשב הזה, בתיקייה `data/`. הקובץ `state.json` מכיל את הרכישות, ועותק יומי נשמר ב-`data/backups/`.

Collectr מציג רק מחיר נוכחי, לכן ההיסטוריה של השווי מתחילה מהיום הראשון שבו האפליקציה רצה, ומתמלאת בכל יום שבו היא מתעדכנת.
